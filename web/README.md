# AgentTrace Visual Report

This directory is a static Reporter for AgentTrace JSON. It contains no diagnosis rules.

The first vertical slice renders the R001 dependency-environment case. The file
`web/data/dependency-environment.json` is intentionally generated by CI from:

```bash
moon run cmd/main inspect . \
  --log fixtures/logs/vitest-missing-matcher.txt \
  --build-exit-code 0 \
  --format json
```

The command returns exit code `1` because a diagnosis was produced. The
`visual-report` workflow verifies the expected category/rule/confidence, writes
the exact JSON into the static bundle, smoke-tests the bundle over HTTP, and
uploads it as an Actions artifact.

The browser code only renders fields that already exist in the generated JSON.
Case title, explanatory copy, and the reproduce command are presentation
metadata; they are not a second diagnosis implementation.
