# AgentTrace Visual Report

This directory is a static Reporter for AgentTrace JSON. It contains no diagnosis rules.

The current bundle renders three reproducible cases generated by the real Native CLI:

1. R001 dependency-environment failure:

```bash
moon run cmd/main inspect . \
  --log fixtures/logs/vitest-missing-matcher.txt \
  --build-exit-code 0 \
  --format json
```

2. R004 explicit branch expectation mismatch:

```bash
moon run cmd/main inspect . \
  --expected-branch __agenttrace_expected_branch__ \
  --format json
```

3. R002 source-located TypeScript compile error:

```bash
moon run cmd/main inspect . \
  --build-log fixtures/logs/tsc-type-error.txt \
  --build-exit-code 2 \
  --format json
```

The R004 command deliberately uses a branch name that the CI checkout will not
match. In real use, replace it with the branch expected by the task.

All three commands return exit code `1` because a diagnosis was produced. The
`visual-report` workflow writes the exact JSON into `web/data/`, validates the
diagnosis contract for each case, smoke-tests all JSON endpoints over HTTP, and
uploads the static bundle as an Actions artifact.

The browser code only selects and renders those generated JSON files. Case
titles, explanatory copy, and reproduce commands are presentation metadata; they
are not a second diagnosis implementation.
